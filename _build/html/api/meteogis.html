meteogis.read_file(file_path, **kwargs)[source]

Read a file (raster or vector), auto-dispatching on file extension.

Tries the driver registry first (covers every registered vector format, plus .tif/.tiff via GTiffDriver). Falls back to GDAL’s generic raster reader for formats with no registered driver (.nc, .hdf, .img, etc.) — GDAL auto-detects those on its own.

Parameters:

  • file_path (str) – Path to the file to read.

  • **kwargs – Forwarded to the matching driver’s read() (or read_raster() on fallback).

Returns:

  • Vector (tuple[list[tuple[shapely.Geometry, dict]], str | None] — (dataset, crs))

  • Raster (via a registered driver, e.g. .tif) (whatever that driver’s) – read() returns (currently the raw gdal.Dataset for GTiffDriver).

  • Raster (fallback, e.g. .nc) (raw gdal.Dataset.)

meteogis.to_file(dataset, file_path, **kwargs)[source]

Write data to a file (raster or vector), auto-dispatching on file extension.

Tries the driver registry first (covers every registered vector format, plus .tif/.tiff via GTiffDriver). Falls back to GDAL’s generic raster writer for formats with no registered driver.

Parameters:

  • dataset (Vector: list[tuple[shapely.Geometry, dict]]) – Raster: gdal.Dataset | np.ndarray Data to write. Matches whatever the corresponding read_file() call for this format would have returned.

  • file_path (str) – Path to write to.

  • **kwargs – Forwarded to the matching driver’s write() (or write_raster() on fallback) — e.g. crs=<WKT or “EPSG:xxxx”> for vector formats, geometry_mode for CSV.
