meteogis.io.drivers.ogr_driver module

class meteogis.io.drivers.ogr_driver.OGRDriver[source]

Bases: Driver

Base class for vector drivers backed by GDAL/OGR vector formats, accessed through geopandas + pyogrio instead of raw osgeo bindings.

Subclasses set name, extensions (from Driver), and ogr_driver_name (the OGR driver short name, e.g. “GeoJSON”, “ESRI Shapefile”, “GPKG” — the same strings GDAL/OGR has always used; pyogrio resolves them without a separately installed libgdal).

Geometries crossing this boundary are always Shapely objects — OGR geometries never leak out to callers, same as before.
