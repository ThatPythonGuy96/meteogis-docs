meteogis.io.raster module

Raster I/O built on rasterio.

rasterio wraps GDAL internally but ships portable, self-contained wheels for Windows/Linux/macOS — so this module needs no system GDAL install on the end user’s machine, unlike the old osgeo-based version.

Plain, in-memory container for a raster.

Replaces the old raw gdal.Dataset handle — no open file handle to manage or leak, just data. Holds everything downstream code (drivers, analysis functions) needs.

meteogis.io.raster.read_raster(path, variable=None)[source]

Open a geospatial raster and read it fully into memory.

Parameters:

  • path (str) – Path to the geospatial dataset.

  • variable (str, optional) – Multi-variable containers (NetCDF, HDF) often have no raster bands at the top level — only “subdatasets”, one per variable. For those, pass the variable name to select which one to read (e.g. variable=”precipitation”). Not needed for single-band/ single-variable files like a plain GeoTIFF.

Return type:

RasterDataset

Raises:

  • FileNotFoundError – If the dataset cannot be opened.

  • ValueError – If the file has no bands and no subdatasets, if it has subdatasets but no variable was specified, or if the given variable isn’t among the file’s subdatasets. In the latter two cases the error message lists what’s actually available.

meteogis.io.raster.write_raster(dataset, path, xsize, ysize, band_count=1, dtype='float32', driver='GTiff', crs=None, geotransform=None, nodata=None)[source]

Write array data to a raster file.

Parameters:

  • dataset (np.ndarray) – 2D array (single band) or 3D array (band, rows, cols) of pixel values.

  • path (str) – Output file path.

  • xsize (int) – Raster width and height in pixels.

  • ysize (int) – Raster width and height in pixels.

  • band_count (int, optional) – Number of bands. Defaults to 1.

  • dtype (str, optional) – Output pixel data type (numpy/rasterio dtype string, e.g. “float32”, “uint8”). Defaults to “float32”.

  • driver (str, optional) – GDAL driver short name. Defaults to “GTiff”.

  • crs (str, optional) – Coordinate reference system as a WKT string or EPSG code (e.g. “EPSG:4326”). rasterio accepts both directly.

  • geotransform (tuple, optional) – GDAL-style geotransform tuple (origin_x, pixel_width, 0, origin_y, 0, pixel_height).

  • nodata (float, optional) – NoData value to set on each band.

Returns:

Path to the written file.
